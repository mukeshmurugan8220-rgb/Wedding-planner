# 💍 Mukesh Weddings — Luxury Wedding Planner

A beautiful, elegant, and responsive wedding planner website designed to showcase luxury wedding services, memorable celebrations, and personalized wedding planning experiences.

## ✨ Features

* 🏡 Elegant and luxurious homepage
* 📱 Responsive design for mobile, tablet, and desktop
* 💒 Wedding planning service sections
* 🌸 Beautiful wedding image gallery
* 💌 Contact form with input validation
* 🎨 Premium colors and elegant typography
* ✨ Smooth scrolling and animations
* 📲 Mobile-friendly navigation
* ⬆️ Back-to-top button
* 📅 Wedding date selection
* 🔗 Social media links

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome
* Unsplash Images

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/mukeshmurugan8220-rgb/Wedding-planner.git
```

### 2. Open the Project Folder

```bash
cd Wedding-planner
```

### 3. Run the Website

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

## 📩 Contact Form

The contact form includes client-side validation. A backend or email service must be connected to receive and process real customer enquiries.

The objective of this project is to create an attractive, user-friendly wedding planner website that presents wedding services, showcases celebrations, and helps visitors explore wedding planning options.
